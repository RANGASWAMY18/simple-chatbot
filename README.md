# Simple Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python.

The chatbot reads the user's input and responds according to predefined keywords and rules.

## Features

- Greeting responses
- How are you response
- Chatbot name response
- Help command
- Thank you response
- Goodbye response
- Quit command
- Unknown question handling

## Technologies Used

- Python
- VS Code
- Git
- GitHub

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python chatbot.py
